ROOT CAUSE ANALYSIS
================================================================================

BUG #1 ROOT CAUSE: TextField Missing initialValue Binding

File: apps/mobile/lib/features/forms/screens/form_viewer_screen.dart
Method: _buildTextInput() (lines ~1913-1950)
Issue: TextField had NO initialValue property
Result: When page returned, TextField displayed empty "" even though answer was stored

Flow:
1. User fills text input Q1 = "A"
   → onChanged updates _questions[0]['answer'] = "A" ✅
   → TextField shows "A" (user just typed it) ✅

2. User navigates to Page 2
   → Widget destroys Q1 TextField
   → _questions[0]['answer'] = "A" remains in memory ✅

3. User navigates back to Page 1
   → NEW TextField instance created
   → NO initialValue binding ❌
   → TextField defaults to empty "" ❌
   → User sees blank field ❌
   → _questions[0]['answer'] = "A" exists but invisible ❌

BUG #2 ROOT CAUSE: HTTP 500 from Backend

- Request structure: ✅ CORRECT
